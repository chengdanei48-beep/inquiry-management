# 画面設計書

状態: **確認事項を反映済み(9章)**。要件定義書 [requirements.md](requirements.md) の機能ID・用語・文字数上限に従う。

## 1. 画面一覧と遷移

アプリは1ページ(`index.html`)で、画面をページ遷移なしで切り替える。画面はURLのハッシュ(`#/...`)で識別し、ブラウザの「戻る」「進む」が使える。

| ID | 画面 | ハッシュ | 機能 |
|---|---|---|---|
| S-01 | 問い合わせ一覧 | `#/inquiries` | F-02、F-10 |
| S-02 | 問い合わせ登録 | `#/inquiries/new` | F-01 |
| S-03 | 問い合わせ詳細 | `#/inquiries/{id}` | F-03〜F-07 |
| S-04 | 集計 | `#/reports` | A-01〜A-06、F-12、F-13 |
| S-05 | マスタ管理 | `#/masters` | F-08、F-09 |

F-11(サンプルデータ投入)は画面を持たず、npm スクリプトで実行する。

```
S-01 一覧 ──[新規登録]──→ S-02 登録 ──[登録]──→ S-03 詳細
   │  └──[行を選択]────────────────────────────→ S-03 詳細
   │                                                │
   │←──────────────[一覧へ戻る]────────────────────┘
ヘッダーのメニューから S-01 / S-02 / S-04 / S-05 へいつでも移動できる
```

## 2. 共通仕様

### 2.1 レイアウト(Chrome、幅1024px以上)

```
┌──────────────────────────────────────────────────────────┐
│ 問い合わせ管理   [一覧][新規登録][集計][マスタ管理]   操作する担当者: [▼山田 太郎] │ ← ヘッダー
├──────────────────────────────────────────────────────────┤
│ (メッセージ領域: 成功・エラー)                                    │
│ (画面の本文)                                                     │
└──────────────────────────────────────────────────────────┘
```

- 現在の画面のメニュー項目は強調表示する(色に加え、太字と下線)。
- 「操作する担当者」は、担当者区分が「担当者」の有効な社員から選ぶ。選択はブラウザに保存する(3章)。
- 担当者が未選択の間は、登録・変更・保存の操作を無効にし、メッセージ領域に「操作する担当者を選択してください」と表示する。閲覧と CSV 出力は可能。

### 2.2 表示の規則

| 項目 | 規則 |
|---|---|
| 日付・時刻 | `YYYY/MM/DD`、`HH:mm`(24時間表記) |
| 対応時間 | `H:mm`(例: `4:30`)。未計測は `-` |
| ステータス | ラベルの文言で表示し、色だけで区別しない。未対応=灰、対応中=青、保留=黄、完了=緑 |
| 優先度 | 「高」「中」「低」の文言で表示する |
| 必須項目 | ラベルに「必須」を併記する(色や記号だけにしない) |
| 文字数 | 自由入力欄の下に「n/50」を表示する |

### 2.3 メッセージ

- メッセージ領域は画面上部に置き、エラーは `role="alert"` とする。成功メッセージは `role="status"` とし、操作後に表示して次の操作で消す。
- 入力エラーは、該当項目の下にその項目のエラー文言を表示し、項目に `aria-invalid="true"` を付ける。複数ある場合は最初の項目にフォーカスを移す。
- 内部情報(SQL・URL・ステータスコード)は表示しない。

| 状況 | 文言 |
|---|---|
| 必須項目の未入力 | 「{項目名}を入力してください」 |
| 文字数超過 | 「{項目名}は50文字以内で入力してください」 |
| 選択肢の未選択 | 「{項目名}を選択してください」 |
| 担当者が未割当で対応中・保留・完了にする | 「担当者を割り当ててください」 |
| 完了時に対応内容が未入力 | 「対応内容を入力してください」 |
| 関連する問い合わせが存在しない | 「指定した問い合わせが見つかりません」 |
| 未完了の担当案件がある社員を無効にする | 「未完了の問い合わせの担当者になっているため、無効にできません」 |
| 同時更新の競合(409) | 「他の担当者が先に更新しました。最新の内容を読み込み直してください」(「再読み込み」ボタンを併記) |
| 問い合わせが存在しない(404) | 「問い合わせが見つかりません」(一覧へ戻るリンク) |
| 通信失敗 | 「通信に失敗しました。時間をおいて、もう一度お試しください」 |
| 想定外のエラー(500) | 「処理に失敗しました。時間をおいて、もう一度お試しください」 |
| 一覧・集計のデータ無し | 「該当するデータはありません」(通信失敗とは区別して表示) |

### 2.4 確認ダイアログ

取り消せない操作にのみ表示する。

- 「完了」にする(S-03): 対応内容の入力欄を含むダイアログ。
- それ以外の操作(登録、保存、変更、コメント追加)は確認なしで実行する。

## 3. S-01 問い合わせ一覧

### 項目・操作

| 区分 | 内容 |
|---|---|
| 絞り込み | ステータス(すべて/各ステータス)、カテゴリ、担当者(すべて/未割当/各担当者)、依頼者の部署、キーワード(件名・内容) |
| ボタン | 「検索」「条件をクリア」「CSV出力」「新規登録」 |
| 一覧の列 | ID、件名、カテゴリ、依頼者(部署)、優先度、ステータス、担当者、受付日時 |
| 並び順 | 既定は受付日時の新しい順。列見出し(優先度、受付日時)の選択で並び替える |
| ページング | 1ページ20件。「前へ」「次へ」と「全N件中 a〜b件」「p/Pページ」を表示する |
| 行の操作 | 行を選択すると S-03 へ移動する(件名をリンクにし、キーボードでも操作できる) |

### 規則
- 検索は「検索」ボタン(またはキーワード欄での Enter)で実行する。条件を変えて検索したら1ページ目に戻る。
- 「CSV出力」は、現在の絞り込み条件と並び順を反映して全件を出力する(ページに関係なく)。
- キーワードに含まれる `%` `_` は文字として扱う。
- 0件の場合は「該当するデータはありません」を表示する。

## 4. S-02 問い合わせ登録

| 項目 | 入力 | 必須 | 規則 |
|---|---|---|---|
| 件名 | テキスト | 必須 | 50文字以内 |
| 内容 | 複数行テキスト | 必須 | 50文字以内 |
| 依頼者 | 選択(有効な社員) | 必須 | 「氏名(部署)」で表示 |
| カテゴリ | 選択(有効なカテゴリ) | 必須 | 表示順に並べる |
| 優先度 | 選択(高・中・低) | 必須 | 既定は「中」 |
| 関連する問い合わせ | 数値(ID) | 任意 | 存在するIDのみ |

- ボタン: 「登録」「キャンセル」(一覧へ戻る)。
- 登録に成功したら S-03 に移動し、「問い合わせを登録しました」を表示する。
- 登録時のステータスは「未対応」、担当者は未割当、受付日時は自動設定(表示も入力もしない)。

## 5. S-03 問い合わせ詳細

```
┌ #12 件名                              [未対応]  優先度: 中 ┐
│ 基本情報(表示のみ)                                          │
│ 依頼者 / カテゴリ / 担当者 / 受付日時 / 更新日時 / 関連する問い合わせ │
│ 対応内容(完了後のみ) / 完了日時 / 対応時間(完了後のみ)           │
├ 操作 ───────────────────────────────────────────────────┤
│ ステータス変更: [対応中にする]    担当者: [▼ 未割当] [割り当てる]   │
│ [編集]                                                          │
├ 対応履歴(古い順)─────────────────────────────────────────┤
│ 2026/10/12 09:30 山田 太郎  ステータスを「未対応」から「対応中」に変更 │
│ コメント: [____________ n/50] [追加]                              │
└────────────────────────────────────────────────────────────┘
```

### 操作の出し分け

| 現在のステータス | ステータス変更のボタン | 担当者割当 | 編集 | コメント |
|---|---|---|---|---|
| 未対応 | 「対応中にする」 | 可 | 可 | 可 |
| 対応中 | 「保留にする」「完了にする」 | 可 | 可 | 可 |
| 保留 | 「対応中に戻す」 | 可 | 可 | 可 |
| 完了 | なし | 不可(非表示) | 不可(非表示) | 可 |

### 規則
- 遷移できないボタンは表示しない(不正な遷移はAPIでも拒否する)。
- 担当者が未割当のとき、「対応中にする」などは操作時に「担当者を割り当ててください」を表示して実行しない。
- 「完了にする」は、確認ダイアログで対応内容(必須、50文字以内)を入力して確定する。確定後、完了は元に戻せないことをダイアログに表示する。
- 「編集」は、件名・内容・カテゴリ・優先度を同じ画面内の入力欄に切り替えて編集する(S-02 と同じ入力規則)。「保存」「キャンセル」を表示する。
- 更新系の操作は、画面を開いた時点の更新日時を送る。競合したら 2.3 の文言を表示する。
- 履歴は古い順に、日時・操作者・内容を表示する。種別(ステータス変更、担当者変更、コメント、編集)を文言で示す。
- 完了済みの場合は「完了済みのため編集できません。再度の対応が必要な場合は、新規に登録してください」を表示し、「新規登録」へのリンクを置く。

## 6. S-04 集計

### 操作

| 区分 | 内容 |
|---|---|
| 期間 | 開始日・終了日(日付入力)。既定は当月1日〜今日。「表示」で集計する |
| 月次保存 | 対象月(月入力)と「月次集計を保存」ボタン。既定は先月 |
| 保存済み月 | 月、保存日時、ファイル(CSV 6件・SVG 6件)へのダウンロードリンクの一覧 |

### 集計の表示
A-01〜A-06 を縦に並べ、各セクションは「見出し・表・グラフ・CSV出力ボタン」で構成する。表を左、グラフを右に置く。

| ID | 表の列 | グラフ |
|---|---|---|
| A-01 | カテゴリ、件数 | 横棒グラフ(カテゴリ別) |
| A-02 | 部署、件数 | 横棒グラフ(部署別) |
| A-03 | カテゴリ、完了件数、平均対応時間 | 横棒グラフ(平均対応時間、`H:mm`) |
| A-04 | 担当者、完了件数、未完了件数 | 担当者ごとの2本の棒(完了・未完了)。凡例を表示 |
| A-05 | 月(YYYY/MM)、件数 | 折れ線グラフ(月別) |
| A-06 | ステータス、件数 | 横棒グラフ(ステータス別) |

### グラフの規則
- 素のJavaScriptでSVGを描画する(外部ライブラリなし)。
- 棒の先端に値を数字で表示する。折れ線の各点にも値を表示する。
- 色だけで区別しない。A-04 は凡例の文言と、完了=塗りつぶし・未完了=斜線のパターンで区別する。
- 各グラフに、見出しと同じ内容の `title` を付け、表で同じ値を確認できるようにする。
- 0件の項目も表に表示する(A-03 の平均対応時間は `-`、グラフでは0)。

### 月次保存
- 「月次集計を保存」で、対象月の1日〜末日を期間として A-01〜A-06 の CSV と SVG を `data/reports/YYYY-MM/` に保存する。
- 既に保存済みの月を保存する場合は、「上書きします」を表示してから実行する(確認ダイアログ)。
- 成功時は「{YYYY/MM}の集計を保存しました」を表示し、保存済み月の一覧を更新する。

## 7. S-05 マスタ管理

「社員」「カテゴリ」の2つのタブで切り替える。

### 社員

| 項目 | 内容 |
|---|---|
| 一覧の列 | 氏名、部署、担当者区分(担当者/一般)、状態(有効/無効) |
| 入力 | 氏名(必須、50文字以内)、部署(必須、50文字以内)、担当者区分(担当者/一般) |
| 操作 | 「追加」「編集」「無効にする」「有効にする」 |

### カテゴリ

| 項目 | 内容 |
|---|---|
| 一覧の列 | 名称、表示順、状態(有効/無効) |
| 入力 | 名称(必須、50文字以内)、表示順(必須、数値) |
| 操作 | 「追加」「編集」「無効にする」「有効にする」 |

### 規則
- 削除はできない。無効にした社員・カテゴリは、新規の選択肢には出ないが、過去の問い合わせでは表示される。
- 追加・編集は、一覧の上のフォーム(追加)と行内の入力欄(編集)で行う。
- 未完了(未対応・対応中・保留)の問い合わせの担当者になっている社員は、無効にできない。「無効にする」を選ぶと、2.3 の文言を表示して拒否する(完了済みの問い合わせにだけ関わる社員は無効にできる)。
