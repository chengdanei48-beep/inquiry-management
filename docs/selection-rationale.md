# 題材の選定理由

課題の候補(レシピ管理、読書記録、競馬アプリ、イベント予定管理、問い合わせ管理)の中から、**問い合わせ管理**を選定した。

## 需要の比較

| 候補 | 需要の目安(調査で確認できた範囲) | 競合・特徴 |
|---|---|---|
| レシピ管理 | 世界市場は2030年までに約13億ドル規模。日本は年率約9.4%で成長予測。国内アプリで累計100万DLの例あり | 競合は多い。個人利用が中心 |
| 読書記録 | 個人向けでは定番ジャンル。ただし利用者数の統計は見つからず | ブクログ・読書メーターが強い。SNS型が主流 |
| 競馬 | JRA売上は約3.25兆円で11年連続増加。ネット投票が5割超 | 公式アプリ(JRA、JRA-VAN)が強い。データ利用や年齢制限に注意 |
| イベント予定管理 | イベント管理ソフトの世界市場は約71億ドル(2024年)。日本は年率約7.0%で成長予測 | 個人向けはカレンダーアプリと競合。主催者向けなら業務系 |
| 問い合わせ管理 | 法人向けの定番カテゴリ。国内シェア首位のサービスは導入9,000社以上 | Zendesk、Freshdeskなどが強い。市場規模の数値は見つからず |

数値は市場調査会社の概要情報によるもので、ジャンル間で単純比較はできない。「需要がある」ことは、競合が多いことと表裏一体である。

## 選定理由

- 実務で需要が確実にある法人向けの定番カテゴリである。
- 「登録・一覧・ステータス変更・担当者割当・履歴」と、設計の見せ場が多い。
- 他の候補に比べ、外部データの利用規約や年齢制限などの論点が少なく、課題として完成させやすい。
