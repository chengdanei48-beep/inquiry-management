4 エンドポイント一覧

19本。機能ID(F-xx / A-xx)は要件定義書のIDです。

F-11(サンプルデータ投入)は画面もAPIも持たず、npm スクリプトで実行します。

5 ステータス遷移

「完了」は最終状態です。再度の対応が必要な場合は、新規の問い合わせとして登録します(関連IDで元の問い合わせとつなげられます)。

6 処理の流れ

6.1 完了にする(検証と結果の分岐)

6.2 同時更新の検出(楽観ロック)

画面を開いた時点の updatedAt を送り、現在の値と違えば 409 で拒否します。

7 対応時間の計算(営業時間・保留除外)

営業時間は平日 9:00〜18:00。例: 金曜 16:30 受付 → 月曜 9:00〜13:00 は保留 → 火曜 10:00 完了。
