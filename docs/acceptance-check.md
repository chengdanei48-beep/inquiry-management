# 受け入れ条件の照合表

要件定義書 [requirements.md](requirements.md) の「8. 受け入れ条件」の各項目を、どのテスト・確認で満たしているかを示す。

- **自動テスト**: `npm test`(`node --test`。テストファイルは `test/`)
- **実ブラウザ確認**: `npm run e2e`(Chrome を操作して、画面を確認する。`scripts/e2e/suites.js`)

## 確認の範囲と限界

- **ブラウザ**: Chrome(最新版)のみ。スマートフォン表示・他のブラウザは、要件の対象外。
- **ネットワーク**: 外部アドレスへの接続の確認は、実行したマシンに loopback 以外のアドレスがある場合に、実際の接続で行う(無い場合はテストを省略する)。
- **性能**: 1つのプロセス・1つのマシンでの計測。同時に多数の利用者がいる状況は、対象外(要件は、少人数のチームでの利用)。
- **キーボード操作**: 新規登録画面で、Tab による移動・Enter・Esc を確認している。すべての画面の全操作を、キーボードだけで網羅して確認しているわけではない(操作は、標準の `button` / `a` / `input` / `select` で構成している)。
